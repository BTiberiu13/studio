# **App Name**: WanderTest

## Core Features:

- DeepSearch: Utilize a large language model as a tool to deep-search attractions, experiences, and points of interest at the user-specified location and timeframe.
- Results Display: Display the AI-generated search results in an easily browsable and sortable list format.
- Category Filter: Allow users to filter search results by categories of interest.
- Itinerary Builder: Enable users to select desired items from the search results and add them to a personal itinerary.
- Save Itinerary: allow user to save his itinerary for easy and fast reaccess.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) for sophistication and exploration.
- Background color: Light gray (#F0F0F0) to ensure readability and a clean interface.
- Accent color: Teal (#009688) for interactive elements and calls to action.
- Body and headline font: 'Inter' sans-serif font, for clear and modern readability.
- Use clear and intuitive icons to represent different categories of attractions and activities.
- Maintain a clean, card-based layout for presenting attractions and itinerary items.
- Incorporate smooth transitions and subtle animations to enhance user engagement.
